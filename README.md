# Feature-weighted maximum representative sampling (FW-MRS)

## Install Requirements
All requirements are listed in the requirements.txt file. The usage of a virtual environment is recommended.
```shell
python3 -m pip install -r requirements.txt
```

## Reproduce results
Run the scripts:\
virtual environment is recommended.
```shell
./downstream_task_experiment.sh
./decomposition_experiments.sh
```

## Reproduce diagrams
Jupyter notebooks to reproduce the diagrams are in /notebooks.
